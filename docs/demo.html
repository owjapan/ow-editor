INTERACTIVE DEMO

記事編集のデモ

本文を書いて、書式や表を編集してみてください。HTMLファイルとしてダウンロードできます。

このデモの保存先は、あなたのブラウザーです。本文・画像を送信するAPIはありません。下書きは同じタブ内に保持します。実際のファイルアップロードには、利用先の画像APIを接続してください。
サーバーへの本文送信なし

エディターを読み込んでいます。表示されない場合は、JavaScriptとファイルの読み込みを確認してください。

出力したHTML

    

    
画像
幅・配置・説明文を試す
「サンプル画像を追加」を押し、画像をクリックすると設定が表示されます。用意した画像だけを使うため、アップロードは行いません。
表
セルを選んで編集する
セルをクリックすると表の操作が表示されます。Shiftを押しながら別のセルをクリックすると、結合する範囲を選べます。
HTML
ソースも編集できる
ツールバーの「〈/〉」から編集できます。「適用」で反映し、「取消」で元の本文へ戻ります。
