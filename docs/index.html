A REUSABLE HTML EDITOR

HTMLを編集する。
どのサービスでも使う。

文字、画像、表をひとつの編集画面で。
編集エンジンから独自実装した、組み込み用エディターの初版です。

デモを試す →ソースを見る ↗

ライセンスキー入力・利用回数の計測なし。自己配信にも共通配信にも。

ひとつのライブラリ、複数のサービスへ
// JS と CSS を読み込んで接続
const editor = new OWEditor.RichTextEditor(
  document.querySelector('#body'),
  {
    messages: OWEditor.messages,
    upload: yourImageUpload
  }
);

// 保存先は、あなたのサービスで
editor.getHTML();

FEATURES

本文編集の道具を、ひと通り。

対応する操作と、初版の範囲を確認できます。

01 / TEXT

文字と段落

見出し、太字、斜体、下線、取消線。書体・サイズ・文字色・背景色、段落配置や箇条書きも設定できます。

BIU背景色H₂
02 / IMAGE

画像と説明文

アップロード関数を接続し、画像の幅・高さ・配置、代替テキストとキャプションを編集。幅はスライダーでも変更できます。

サンプル画像で試す →
03 / TABLE

表を組み立てる

行・列の追加と削除、セル結合・分割、見出し切替。セルの背景・枠線・幅・配置まで操作できます。

項目内容
04 / WORKFLOW

編集を続けやすく

Undo / Redo、検索・置換、全画面表示、文字数表示、HTMLソース編集。未保存の本文は、同じタブで復旧できます。

05 / SANITIZATION

HTMLを安全化

貼り付け・ソース編集の実行可能なタグや危険なURLを除去。HTML安全化にはDOMPurifyを同梱しています。

保存権限・画像の実体検査・表示時の安全化は、利用先のサーバーでも行います。

06 / INTEGRATION

サービスごとに接続

画像APIと記事保存先を指定できます。同一フォームの複数フィールドにも対応し、編集中の設定や画像送信があれば保存を止めます。

複数フィールドを試す →
